## 💪 How to Use the Exercise Files

Each exercise file contains:
- **Function templates** with TODO comments
- **Instructions** explaining what to implement
- **Test sections** to verify your solutions

### Working Through Exercises

1. Open an exercise file
2. Read the TODO comments carefully
3. Implement the function
4. Uncomment the test code at the bottom
5. Run the file: `python exercises_basics.py`
6. Debug until all tests pass
7. Move to next exercise

Example workflow:
```bash
# Start with basics
python exercises_basics.py

# Move to data structures
python exercises_data_structures.py

# Finally, NVIDIA-focused topics
python exercises_nvidia_focused.py
```
